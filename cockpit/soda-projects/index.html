Remove my workspace

This permanently removes your workspace account, home, independent clone, dependencies, processes, project state, and uncommitted work. The shared project, other workspaces, and canonical repository are not deleted.

Remove project from Soda

This permanently removes all local workspace accounts, homes, clones, dependencies, and uncommitted work for this project. The canonical repository is not deleted.

Remove person from Soda OS

This permanently removes local Soda workspaces, then asks Forgejo to delete the account without --purge, then removes the primary Linux account. Forgejo deletes the account, its SSH and GPG keys, access tokens, email addresses, settings, and user data. Its native rules keep issues, pull requests, and comments as deleted-user history, except configured recent-comment deletion. Forgejo refuses if the person owns a repository or package, belongs to an organization, or is its last administrator; then the Linux account remains so an administrator can retry.
