# Base system attribution

Soda OS 0.2.0 uses the Rocky Linux 10.2 Anaconda installer runtime and installs
current Rocky Linux 10 packages, including the Linux kernel, GNU C Library,
systemd, GNU Coreutils, RPM, DNF, and other upstream open-source projects under
their respective licenses.

Rocky Linux is the technical package source. Soda OS is an independent
development appliance and is not endorsed by the Rocky Enterprise Software
Foundation.
