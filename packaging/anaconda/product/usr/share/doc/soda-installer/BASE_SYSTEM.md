# Base system attribution

Soda OS 0.1.0 is built from Rocky Linux 10.2 packages and uses the Anaconda
installer, Linux kernel, GNU C Library, systemd, GNU Coreutils, RPM, DNF, and
other upstream open-source projects under their respective licenses.

Rocky Linux is the technical package source. Soda OS is an independent
development appliance and is not endorsed by the Rocky Enterprise Software
Foundation.
